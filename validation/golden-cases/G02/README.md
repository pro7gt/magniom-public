# Golden Case 02: High-Convergence Personalisation

## Purpose
Demonstrate that when resting-state fMRI is high quality (reliability = 0.88) and reveals significant incremental circuit concordance (+0.18 over baseline) within the anatomical envelope (8.25mm), Magniom promotes the connectome-refined target to Primary 1 while preserving the evidence-only prior as Additional A for counterfactual inspection.

## Expected Behaviour
- Primary 1: Connectome-refined convergent target `CAND-CONVERGENT-G02` (`[-44, 40, 34]`, Tier T1)
- Additional A: Evidence-only baseline anchor `CAND-EVIDENCE-LDLPFC` (`[-38, 44, 30]`)
- Personalisation: `qualified`
- Convergence: `high` (8.25 mm)
