# Golden Case 07: Mixed Dysphoric/Anxiosomatic Phenotype

## Purpose
Demonstrate dual-hypothesis allocation for multi-domain phenotype without cross-contamination.

## Clinical Context
- **Condition**: MDD with co-morbid high dysphoria and high anxiety
- **Imaging**: High-quality resting-state fMRI

## Expected Behaviour
- Primary 1: Convergent Left DLPFC (`TF-MDD-CONVERGENT-LDLPFC-001`, `[-44, 40, 34]`)
- Primary 2: Anxiosomatic DMPFC (`TF-MDD-ANXIOSOMATIC-DMPFC-001`, `[-6, 24, 48]`)
- Personalisation: `qualified`
