# Golden Case 05: Anxiosomatic-Dominant Dual-Circuit

## Purpose
Demonstrate dual-circuit target selection when anxiosomatic distress is the primary clinical priority. Magniom promotes both a connectome-refined left-prefrontal target (Primary 1) and a distinct Anxiosomatic DMPFC circuit target (Primary 2, `TF-MDD-ANXIOSOMATIC-DMPFC-001`, MNI `[0, 48, 46]`), emphasizing that Primary 2 represents a distinct clinical hypothesis.

## Expected Behaviour
- Primary 1: Connectome-refined left prefrontal convergent target `CAND-CONVERGENT-G05` (`[-44, 40, 34]`, Tier T1)
- Primary 2: Anxiosomatic DMPFC circuit target `CAND-ANXIOSOMATIC-DMPFC-G05` (`[0, 48, 46]`, Tier T2)
- Additional A: Evidence-only baseline anchor `CAND-EVIDENCE-LDLPFC` (`[-38, 44, 30]`)
- Personalisation: `qualified`
- Clinical Coverage: Primary domain `DOMAIN-MDD-ANXIOSOMATIC-001`, secondary `DOMAIN-MDD-DYSPHORIC-001`
