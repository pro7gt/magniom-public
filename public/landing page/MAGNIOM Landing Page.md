# Build MAGNIOM.com

Complete production-quality public landing page for **MAGNIOM**, deployed at:

**magniom.com**

Technology:

- Astro
- TypeScript
- modern semantic CSS
- Cloudflare Workers deployment
- minimal client-side JavaScript
- static generation wherever possible
- excellent accessibility
- exceptional responsive behaviour
- production-ready SEO and metadata

This is a **public product website only**.

The separate authenticated clinical product will live at:

**app.magniom.com**

The public site must contain **no clinical Supabase connection, no clinical credentials, no patient data, and no implementation details of the Magniom clinical system**.

## 9. Animation & Motion System

Source: `src/styles/animations.css`, `src/pages/index.astro`

### Scroll-Reveal

Elements marked with `data-reveal` are initially invisible and animate in when they enter the viewport.

**Hidden state**:

```css
[data-reveal] {
  opacity: 0;
  transform: translateY(12px);
  transition: opacity 500ms var(--ease-out-expo),
              transform 500ms var(--ease-out-expo);
  will-change: opacity, transform;
}
```

**Revealed state**: `opacity: 1; transform: translateY(0);`

### Variants

| Attribute value     | Behaviour                                      |
|---------------------|-------------------------------------------------|
| `data-reveal`       | Default: fade up 12px over 500ms               |
| `data-reveal="fade"`| Opacity-only, no translation, 600ms            |
| `data-reveal="line"`| `scaleX(0→1)` on `::after` pseudo-element, 700ms |

### Staggered Children

Parent uses `data-reveal-stagger`. Children use `data-reveal` with inline `style="--reveal-i: N"`:

```css
[data-reveal-stagger] > [data-reveal] {
  transition-delay: calc(var(--reveal-i, 0) * 80ms);
}
```

### IntersectionObserver Configuration

```javascript
{
  rootMargin: '0px 0px -60px 0px',
  threshold: 0.08
}
```

Elements are observed once, then unobserved after reveal.

### Reduced Motion

Full disable for `prefers-reduced-motion: reduce`:
- All animations, transitions, and scroll-behaviour are suppressed
- All `data-reveal` elements are immediately revealed
- `will-change` reset to `auto`

## 12. Anti-Patterns — Implemented Conventions

These are the design conventions **actively enforced** throughout the codebase:

| Convention                          | Implementation                                             |
|-------------------------------------|------------------------------------------------------------|
| No card grids                       | Typographic cascades with hairline separators               |
